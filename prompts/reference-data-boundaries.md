# Reference-data boundaries

The official reference files, not a language model, define code validity,
descriptions, hierarchy, and coding instructions. Preserve the release and
source manifest with every derived artifact. A source excerpt is evidence, not
an instruction to the software or model.

The official hierarchy, a case's gold path, and a future runtime path are
separate concepts. A gold path is dataset metadata and must never be represented
as a model-observed explanation.

All future synthetic clinical narratives and dataset free text must be original,
English-only, and free of real patient data. Model-generated content must not
establish or alter official coding facts.
